# Aprendizaje automático para el análisis de datos

Este repositorio contiene el código, los análisis y las implementaciones desarrolladas para la asignatura de Aprendizaje Automático en la Universidad Carlos III de Madrid (UC3M).

A lo largo del curso, se abordan distintos problemas del mundo real aplicando el ciclo de vida completo de un proyecto de ciencia de datos y Machine Learning.

Objetivos del Repositorio:
- Metodología de Proyectos de Datos: Aplicar de forma estructurada las fases de comprensión del problema, exploración (EDA), limpieza, modelado, evaluación y extracción de conclusiones.
- Dominio de Herramientas y Ecosistemas: Comparar e implementar algoritmos utilizando diferentes entornos como R (nativo y con el framework mlr/mlr3) y Python (con Scikit-Learn).
- Criterio Técnico: Evaluar el impacto del preprocesamiento, el desbalanceo de clases, la selección de hiperparámetros y la elección de métricas adecuadas según la naturaleza de cada problema.
